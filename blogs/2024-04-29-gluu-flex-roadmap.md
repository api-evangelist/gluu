<p>As Flex is a commercial distribution of the Janssen Project, check the Janssen Nightly Build <a href="https://github.com/JanssenProject/jans/releases">changelog</a> and <a href="https://github.com/JanssenProject/jans/issues">issues</a>. You can also check the Nightly Build <a href="https://github.com/GluuFederation/flex/releases">changelog</a> for the Admin UI.  Gluu 4 is considered a stable release&#8211;meaning no major features are planned.</p>
<h3>Gluu Flex &#8211; Q3 2023</h3>
<ul>
<li>New endpoint for &#8220;OAuth 2.0 for First-Party Native Applications&#8221; <a href="https://www.ietf.org/archive/id/draft-parecki-oauth-first-party-native-apps-00.html">draft</a></li>
<li>Support for new parameter for &#8220;Use of Attestation in OAuth2 Dynamic Client Registration&#8221; <a href="https://www.ietf.org/archive/id/draft-tschofenig-oauth-attested-dclient-reg-00.html">draft</a></li>
<li>New component: Jans Link Syncronization Server (LDAP or Keycloak as identity source)</li>
<li>New Component: Keycloak SAML IDP</li>
<li>Ecommerce SMB License for 1600 MAU or less</li>
<li>Support for FIPS profile using Jans RHEL 8</li>
</ul>
<h3>Gluu 4 &#8211; Q3 2023</h3>
<ul>
<li>Bug fixes for oxTrust Admin UI update</li>
<li>MAU report in oxTrust</li>
</ul>
<h3>Gluu Flex &#8211; Q4 2023</h3>
<ul>
<li> Bi-directional Keycloak Syncronization</li>
<li> Support for one-time use SSA statements</li>
<li>Support &#8220;Grant Management for OAuth 2.0&#8221; <a href="https://openid.net/specs/oauth-v2-grant-management.html">draft</a></li>
</ul>
<h3>Gluu 4 &#8211; Q4 2023</h3>
<ul>
<li>No new features planned</li>
